# BridgeTap 1.1.0 — Premiers replays et personnalisation des coordonnées

Minecraft **1.8.9** — édition **Ornithe / Legacy Fabric**.

## Ajouté

- Enregistrement des déplacements et des blocs, sauvegarde du replay avec la run et première vue de replay 3D.
- Galerie avec recherche, cartes et détails des runs.
- Choix entre l’overlay des coordonnées et leur envoi dans le chat en fin de run.
- Choix des couleurs des différents éléments du HUD.

## Corrigé

- Libellé No Gain et application du réglage qui affiche ou masque le type de gain.

## Téléchargements

- `BridgeTap-1.1.0.jar` : Ornithe / Legacy Fabric 1.8.9.
- `SHA256SUMS.txt` : sommes SHA-256 des JAR de cette release.

Installe un seul JAR BridgeTap dans le dossier `mods` de l’instance correspondante, puis redémarre Minecraft avec Java 8.

## Provenance de l’archive

Les binaires originaux sont conservés sans recompilation. Commit d’archivage initial : [`087ffbb`](https://github.com/sgggnnn/bridgetap/commit/087ffbb71de4b8fa4c5e4c66bf95f2c77293caf7).
