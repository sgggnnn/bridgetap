# BridgeTap 1.6.0 - Islands, clips and replay organization

Minecraft **1.8.9** - **Forge** and **Ornithe / Legacy Fabric** editions.

## Added and fixed

- Final release of the dev.11 code, including all 1.6 development features.
- Copy both islands from a replay; preview and position start/finish separately, change their distance, rotate, rename, export and apply named presets in one click.
- Fixed preset anchoring against original start-island geometry so moving the camera or starting a run one block away does not shift a new preset.
- Focus mode hides surrounding native terrain and filters remote spatial sounds while preserving local interactions and non-positional interface audio.
- Readable island export filenames with numbered duplicates; older UUID exports are renamed when opening the island library.
- Windows rolling H.264 video buffer with default-output audio, 15/30/60-second windows, 60/120 FPS options, hardware encoder selection and bounded memory/disk usage.
- Parallel image conversion for 120 FPS; the existing 60 FPS conversion path is retained.
- Default replay file manager with server folders, search, sorting, successful-only and imported-only filters, expanded bridge coordinates and protected saves.
- Optional deletion of unprotected failed runs after 48 hours, OFF by default.
- Client-only appearance selection for tracked placed blocks.

## Upgrade notes

- Replace the old BridgeTap JAR with exactly one matching edition and restart Minecraft.
- Position and save legacy presets once more to use the fixed island anchor. Existing replay/island data remains readable.
- The video buffer starts OFF each launch. Enable it before playing; F9 saves the recent buffer.
- Windows audio captures the default output, including other applications on that device; no microphone is captured. Other platforms use the silent compatibility exporter.
- Actual 120 FPS capture requires a game frame rate of at least 120, compatible GPU readback and sufficient encoder throughput. Disable VSync or raise the game FPS cap if needed.
- Focus sound filtering uses source positions; Minecraft 1.8.9 sound packets do not identify the originating player.

## Validation

- Replay, island, preset, folder, retention, audio-policy and capture regression suites.
- Native MP4/AAC exports at 60 and 120 FPS over 30 seconds, decoded frame counts and distinct-frame checks.
- All 43 native hooks/accessors and real Forge/LaunchWrapper startup, including native island placement, stable preset positions and Focus sound filtering.
- Actual menu drawing and interaction checks. Automated tests do not replace in-game rendering/performance checks with other installed mods.
