# BridgeTap 1.7.4 - Windows update installation (local build)

Fixes an update that downloaded and verified correctly but failed to install with `Connection reset` when Minecraft closed on Windows. The helper now accepts a reset after authenticating the parent game connection. A reset before authentication still fails without touching the installed JAR.

Versions 1.7.2 and 1.7.3 contain the old installer. Install this fix manually once, with Minecraft closed and only one BridgeTap JAR in the active profile's mods folder. Existing replays, islands and configuration remain unchanged.

Regression checks reproduce the old failure with an abortive TCP close and check authenticated reset recovery, rejection before authentication, normal shutdown, checksum validation, collisions, Windows locks, backups and unrelated files.
