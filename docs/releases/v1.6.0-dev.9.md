# BridgeTap 1.6.0-dev.9 - LWJGL GPU-fence compatibility

**Historical development pre-release.** Superseded by [BridgeTap 1.6.0](https://github.com/sgggnnn/bridgetap/releases/tag/v1.6.0).

Minecraft **1.8.9** - **Forge** and **Ornithe / Legacy Fabric** editions.

## Changes in this build

- Resolve GPU fence calls using the active runtime API: GLSync objects on LWJGL 2 and long handles on LWJGL 3/adapters.
- Avoid the NoSuchMethodError that forced high-rate capture into the slower compatibility path.

## Downloads

- `BridgeTap-1.6.0-dev.9-Forge-1.8.9.jar`: Forge 1.8.9.
- `BridgeTap-1.6.0-dev.9.jar`: Ornithe / Legacy Fabric 1.8.9 using Ornithe intermediary mappings.
- `SHA256SUMS.txt`: SHA-256 checksums for both editions.

Install one edition in the instance's `mods` folder and restart Minecraft.

## Historical source availability

The attached JARs are the original preserved binaries for this development build. A separate source snapshot was not retained at the time. This tag's automatic source archives contain a binary manifest and checksums, **not a rebuildable historical code snapshot**. Complete consolidated sources are available in [v1.6.0](https://github.com/sgggnnn/bridgetap/tree/v1.6.0).

Later builds fix known issues in these historical previews. Install the final release for normal use.
