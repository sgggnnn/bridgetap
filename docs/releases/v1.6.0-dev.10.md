# BridgeTap 1.6.0-dev.10 - Hardware clip buffer, presets, Focus and protected saves

**Historical development pre-release.** Superseded by [BridgeTap 1.6.0](https://github.com/sgggnnn/bridgetap/releases/tag/v1.6.0).

Minecraft **1.8.9** - **Forge** and **Ornithe / Legacy Fabric** editions.

## Changes in this build

- Continuous native H.264 rolling disk buffer on Windows, hardware encoder selection and MP4 remuxing with output audio.
- Bounded reusable raw-frame memory and up to a 2 GiB segment buffer instead of the short PNG memory ring.
- Named one-click island presets, independent start/finish positioning and larger v4 island templates with explicit part membership.
- Focus mode and client-only placed-block appearance selection.
- Protected Save replay action and optional cleanup of unprotected failed recordings after 48 hours.
- Successful-only and imported-only filters in the default replay file manager.

## Downloads

- `BridgeTap-1.6.0-dev.10-Forge-1.8.9.jar`: Forge 1.8.9.
- `BridgeTap-1.6.0-dev.10.jar`: Ornithe / Legacy Fabric 1.8.9 using Ornithe intermediary mappings.
- `SHA256SUMS.txt`: SHA-256 checksums for both editions.

Install one edition in the instance's `mods` folder and restart Minecraft.

## Historical source availability

The attached JARs are the original preserved binaries for this development build. A separate source snapshot was not retained at the time. This tag's automatic source archives contain a binary manifest and checksums, **not a rebuildable historical code snapshot**. Complete consolidated sources are available in [v1.6.0](https://github.com/sgggnnn/bridgetap/tree/v1.6.0).

Later builds fix known issues in these historical previews. Install the final release for normal use.
