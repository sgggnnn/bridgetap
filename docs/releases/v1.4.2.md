# BridgeTap 1.4.2 — Live coordinate display restored

Minecraft **1.8.9** — **Ornithe / Legacy Fabric** edition.

## Fixed

- Restored the regular bridge coordinates HUD during normal gameplay.
- Restored the Player XYZ line above the hotbar, without the detailed replay-only telemetry.
- Restored coordinate chat output at the end of an attempt.

## Downloads

- `BridgeTap-1.4.2.jar`: Ornithe / Legacy Fabric 1.8.9.
- `SHA256SUMS.txt`: SHA-256 checksums for this release's JARs.

Install only one BridgeTap JAR in the matching instance's `mods` folder, then restart Minecraft with Java 8.
