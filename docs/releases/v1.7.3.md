# BridgeTap 1.7.3 - Jump details, default islands and confirmed updates

- Adds **Both axes + X-Z difference**, showing both sampled horizontal decimals and their signed difference, with independent previous-tick X/Z decimals when Velo is enabled.
- Enable **Velo Z decimals (jump -1t)** to show `584/289`: the jump coordinate followed by the existing previous-tick Z decimal. The Velo color remains independent.
- Enable **Jump viewing angle (yaw)** in BridgeTap settings or the OneClient HUD settings. Each jump records its actual horizontal viewing angle, normalized to -180 through +180 degrees. Coordinate sampling offsets do not shift the angle's timestamp.
- Failed runs show **Fail Tap/4b** samples at 9 and 12 ticks after the last jump, including the configured coordinate offset. Missing samples are omitted. The normal All statistics display identifies the timing on each row.

## Default islands and updates

- Includes Default, Halloween, Summer, Winter, Fall Island and Speedcubing scenery, each with both endpoints. The Defaults tab keeps built-in templates separate from personal islands; Save a copy creates an editable personal version.
- Checks the latest stable GitHub release and asks before downloading the matching edition. Downloads are verified against GitHub SHA-256, size and Minecraft/mod metadata.
- Replaces the old JAR after Minecraft exits, retaining a backup. Offers same-profile OneClient restart where supported; other launchers require manual relaunch. Checks can be disabled or run manually in Settings > Updates.

## Installation and testing

Minecraft **1.8.9**, with separate **Forge** and **OneClient / Ornithe Fabric** downloads. Install exactly one edition. The OneClient JAR uses Ornithe mappings and is not compatible with arbitrary Legacy Fabric/Yarn profiles.

Replace the previous JAR and restart Minecraft. Existing saved replay summaries remain unchanged. Native video/audio tools remain a separate optional ZIP, extracted into the Minecraft game directory to create `config/bridgetap/tools`.

To test automatic installation, start the local update-capable **1.7.2** build. It should offer this **1.7.3** release at the title menu. A running 1.7.3 correctly reports that it is already current. Versions before 1.7.2 require manual installation once.

Validation: both editions compile; core/update/clip regressions pass; targeted dual-axis/format/color/config regressions and UI interaction previews pass; Forge LaunchWrapper/Mixin loading and 43 native hook checks pass. Restarting an actual OneClient profile still needs live user testing. See [update behavior and limits](https://github.com/sgggnnn/bridgetap/blob/v1.7.3/docs/UPDATES.md).
