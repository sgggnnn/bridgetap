# BridgeTap 1.4.0 — Bibliothèque, partage et POV continue

Minecraft **1.8.9** — édition **Ornithe / Legacy Fabric**.

## Ajouté

- Renommage persistant des replays, recherche par nom et tri par date, temps ou nom.
- Export et import de fichiers .btreplay autonomes pour partager les enregistrements.
- Mesure de la distance entre les bords des plateformes et de leur différence de hauteur lorsque les marqueurs enregistrés le permettent.
- POV continue suivant les déplacements et rotations du bridge enregistré.

## Conservé

- Télémétrie détaillée par tick, favoris et lecture des anciens formats de replay.

## Téléchargements

- `BridgeTap-1.4.0.jar` : Ornithe / Legacy Fabric 1.8.9.
- `SHA256SUMS.txt` : sommes SHA-256 des JAR de cette release.

Installe un seul JAR BridgeTap dans le dossier `mods` de l’instance correspondante, puis redémarre Minecraft avec Java 8.

## Provenance de l’archive

Les binaires originaux sont conservés sans recompilation. Commit d’archivage initial : [`abada5d`](https://github.com/sgggnnn/bridgetap/commit/abada5dfc135d91463caf66409a9d6a90026c5ca).

Cette version intermédiaire n’a pas de commit source dédié. Le tag correspond au premier commit contenant son JAR ; les sources de ce commit portent la version **1.4.3**. Pour installer cette version précise, utilise les JAR joints à la release.
