# BridgeTap 1.2.0 — Lecture native dans Minecraft

Minecraft **1.8.9** — édition **Ornithe / Legacy Fabric**.

## Ajouté

- Lecture du replay dans un monde Minecraft local avec les textures et modèles des blocs.
- Fantôme utilisant le pseudo, le skin, les rotations, le sneak et les animations enregistrés ; hitbox blanche visible.
- Reconstruction des placements de blocs au fil du temps, avec retrait et restauration lors des retours arrière.
- Contrôles dans la hotbar pour la lecture, la pause, les déplacements temporels et la vitesse, avec messages dans l’Action Bar.
- Favoris dans la galerie.

## À savoir pour cette archive

- Les corrections de déplacement de la caméra sont arrivées dans les versions 1.2.1 et 1.2.2.

## Téléchargements

- `BridgeTap-1.2.0.jar` : Ornithe / Legacy Fabric 1.8.9.
- `SHA256SUMS.txt` : sommes SHA-256 des JAR de cette release.

Installe un seul JAR BridgeTap dans le dossier `mods` de l’instance correspondante, puis redémarre Minecraft avec Java 8.

## Provenance de l’archive

Les binaires originaux sont conservés sans recompilation. Commit d’archivage initial : [`edacc4e`](https://github.com/sgggnnn/bridgetap/commit/edacc4efc60a4d53ab6d9c7d8151509c63fd0833).

Cette version intermédiaire n’a pas de commit source dédié. Le tag correspond au premier commit contenant son JAR ; les sources de ce commit portent la version **1.2.2**. Pour installer cette version précise, utilise les JAR joints à la release.
