# BridgeTap 1.7.5 - Axis delta and jump-angle colors

Minecraft **1.8.9**, with separate **Forge** and **OneClient / Ornithe Fabric** editions. Install exactly one edition.

## Added

- Independent **Axis delta positive**, **Axis delta negative** and **Jump angle** colors in Settings > Customize colors.
- Native OneClient RGB pickers for the same components in the coordinate HUD's Settings tab. Individual component colors take precedence over a uniform HUD text override.
- Updated live preview and a compact element list that keeps every color reachable.
- Existing speed-delta and tick-text colors remain independent. Defaults preserve the previous green/red/gray appearance.

## Fixed

- Includes the local 1.7.4 Windows update fix: a verified download no longer fails installation when the authenticated parent connection closes with Connection reset. A reset before authentication is rejected without replacing the installed mod.

## Upgrade and auto-update test

The old installer is part of the running mod. **1.7.2 and 1.7.3 must be replaced manually once** to obtain this fix. To test the complete auto-update flow, install the supplied local **1.7.4** build with Minecraft closed, then start the game and accept the offered **1.7.5** update at the title menu. The replacement finishes after the game exits; the old JAR is retained as a backup. Supported OneClient profiles can request restart; other launchers require manual relaunch.

Existing replays, islands and configuration are preserved. Native clip tools remain a separate optional ZIP extracted into the Minecraft directory to create `config/bridgetap/tools`.
