# BridgeTap 1.4.3 — Options d’affichage et vitesse de lecture

Minecraft **1.8.9** — édition **Ornithe / Legacy Fabric**.

## Ajouté

- Option Replay info pour afficher ou masquer l’ensemble du panneau d’informations du replay.
- Mode LAST_TURN pour afficher uniquement les coordonnées du dernier saut et du turn.
- Choix entre les libellés No Gain et No Gay pour l’indicateur, avec visibilité toujours contrôlée par Gain type.

## Modifié

- Retour du réglage de vitesse via une horloge au slot 4 : 0.25x, 0.5x, 1x, 2x et 4x.
- Suppression de Player XYZ hors replay tout en conservant les coordonnées classiques de bridge.

## Téléchargements

- `BridgeTap-1.4.3.jar` : Ornithe / Legacy Fabric 1.8.9.
- `SHA256SUMS.txt` : sommes SHA-256 des JAR de cette release.

Installe un seul JAR BridgeTap dans le dossier `mods` de l’instance correspondante, puis redémarre Minecraft avec Java 8.

## Provenance de l’archive

Les binaires originaux sont conservés sans recompilation. Commit d’archivage initial : [`abada5d`](https://github.com/sgggnnn/bridgetap/commit/abada5dfc135d91463caf66409a9d6a90026c5ca).
