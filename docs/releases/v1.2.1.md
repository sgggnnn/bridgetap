# BridgeTap 1.2.1 — Independent free camera and gallery restoration

Minecraft **1.8.9** — **Ornithe / Legacy Fabric** edition.

## Fixed

- Restored the previous gallery interface while retaining the native replay engine.
- Made the replay camera independent of the live player and controllable with Minecraft keybindings during playback or pause.
- Separated the replay render context and controller, restoring the live client after rendering.
- Reused renderer resources and cleaned up replay-world buffers.

## Downloads

- `BridgeTap-1.2.1.jar`: Ornithe / Legacy Fabric 1.8.9.
- `SHA256SUMS.txt`: SHA-256 checksums for this release's JARs.

Install only one BridgeTap JAR in the matching instance's `mods` folder, then restart Minecraft with Java 8.

## Archive provenance

The original binaries are preserved without recompilation. Original archival commit: [`edacc4e`](https://github.com/sgggnnn/bridgetap/commit/edacc4efc60a4d53ab6d9c7d8151509c63fd0833).

This intermediate version does not have a dedicated source commit. Its tag points to the first commit containing its JAR; the sources in that commit identify themselves as version **1.2.2**. Use the attached JARs to install this exact version.
