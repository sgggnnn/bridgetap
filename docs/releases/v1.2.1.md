# BridgeTap 1.2.1 — Caméra libre indépendante et retour à la galerie

Minecraft **1.8.9** — édition **Ornithe / Legacy Fabric**.

## Corrigé

- Retour à l’interface de galerie précédente tout en conservant le moteur de replay natif.
- Caméra de replay indépendante du joueur réel, pilotée par les touches Minecraft pendant la lecture ou la pause.
- Séparation du contexte de rendu et du contrôleur du replay, avec restauration du client après le rendu.
- Réutilisation des ressources du renderer et nettoyage des buffers du monde de replay.

## Téléchargements

- `BridgeTap-1.2.1.jar` : Ornithe / Legacy Fabric 1.8.9.
- `SHA256SUMS.txt` : sommes SHA-256 des JAR de cette release.

Installe un seul JAR BridgeTap dans le dossier `mods` de l’instance correspondante, puis redémarre Minecraft avec Java 8.

## Provenance de l’archive

Les binaires originaux sont conservés sans recompilation. Commit d’archivage initial : [`edacc4e`](https://github.com/sgggnnn/bridgetap/commit/edacc4efc60a4d53ab6d9c7d8151509c63fd0833).

Cette version intermédiaire n’a pas de commit source dédié. Le tag correspond au premier commit contenant son JAR ; les sources de ce commit portent la version **1.2.2**. Pour installer cette version précise, utilise les JAR joints à la release.
