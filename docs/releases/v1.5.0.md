# BridgeTap 1.5.0 — Visual HUD studio, replay library and opening detection

Minecraft **1.8.9** — **Forge** and **Ornithe / Legacy Fabric** editions.

## Added

- Visual HUD layout studio: select an overlay, drag it into position, resize with its lower-right handle, snap to center/edge guides, and save separate positions and scales for bridge coordinates, replay information, and recorded inputs.
- A replay-only input HUD with direction arrows, a jump bar, LMB and RMB. It follows recorded held/pressed inputs, including short clicks, and stays synchronized while paused or seeking.
- Detection for **1.0 Flat (3 ticks)**. The existing **1.05 Flat (4 ticks)** remains distinct.
- Opening-only **5b Late** after a 1.0 Flat and **6b Late** after a 1.05 Flat: the first follow-up jump must occur 9 ticks later, advance three block columns along the bridge axis, rise one block, and have observed placement evidence. Ordinary two-column tap speeds and later jumps do not qualify.
- Replay filtering by result, axis, technique, playable recording/summary, and inclusive minimum/maximum time. Filters combine with multi-term, case/accent-insensitive search.
- Date, run time, name and jump-count sorting in both directions, with deterministic ties and persisted preferences.

## Redesigned

- One Recent / Saved / Favorites navigation bar, a unified search/filter/sort row, and a Tools menu for secondary actions.
- Replay cards with favorite badges, clear status/time rows and Watch buttons.
- Details split into Metadata, Map Info and Performance Breakdown, with Save/Rename/Export actions and a primary **PLAY REPLAY** button.
- Settings grouped into HUD & Positioning, Detection & Calculations, and Overlay & Replay, using consistent toggles and steppers.
- Overlay colors use filled swatches, a strong selection marker, reset actions and a live HUD preview.

## Changed

- A **5-client-tick cooldown** after success or failure prevents immediate re-counting. Ignored placements do not enter the completed replay, and a new attempt cannot begin while still standing on the finish plate.
- Jump and plate offsets default to **0**. Existing saved custom values are retained; **Reset offsets** sets both to zero.
- **Only the barrier exits a replay.** The configured library key and Escape no longer stop playback. World-change/disconnection cleanup is retained.
- Menu text remains in English. Existing replay files remain compatible.

## Validation

- Thirteen Java regression programs covering existing replay behavior, opening detection, filters, sorting, input display and saved HUD layout.
- Native hook checks on both loaders and real Forge/LaunchWrapper startup, including the Forge coordinates HUD and synthetic-chunk rendering regression.
- Previews from the real screen drawing paths with Minecraft bitmap font metrics, plus interaction checks for filters, sorting, color selection and dragging.
- Graphics and compatibility with other installed rendering mods still need an in-game check.
