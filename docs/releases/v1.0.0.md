# BridgeTap 1.0.0 — First bridge HUD and run history

Minecraft **1.8.9** — **Ornithe / Legacy Fabric** edition.

## Added

- Bridge and jump tracking: coordinates, deltas, ticks, timing, and turn detection.
- Configurable HUD position, scale, background, shadow, display modes, and visibility while F3 is open.
- Recent run history and saved run summaries.
- Jump and arrival tick offsets, plus a Gain / No Gain indicator.

## Downloads

- `BridgeTap-1.0.0.jar`: Ornithe / Legacy Fabric 1.8.9.
- `SHA256SUMS.txt`: SHA-256 checksums for this release's JARs.

Install only one BridgeTap JAR in the matching instance's `mods` folder, then restart Minecraft with Java 8.

## Archive provenance

The original binaries are preserved without recompilation. The historical `BridgeTap.jar` file is distributed as `BridgeTap-1.0.0.jar`, with identical contents. Original archival commit: [`327bb40`](https://github.com/sgggnnn/bridgetap/commit/327bb40abc4b7c3dedb7b99f664ebb6246e2e8ce).
