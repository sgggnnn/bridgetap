# BridgeTap 1.0.0 — Premier HUD et historique des bridges

Minecraft **1.8.9** — édition **Ornithe / Legacy Fabric**.

## Ajouté

- Suivi des bridges et des sauts : coordonnées, écarts, ticks, temps et détection du turn.
- HUD configurable avec position, taille, fond, ombre, modes d’affichage et visibilité avec F3.
- Historique récent et sauvegarde des résumés de runs.
- Réglages des offsets des sauts et de l’arrivée, ainsi que de l’indicateur Gain / No Gain.

## Téléchargements

- `BridgeTap-1.0.0.jar` : Ornithe / Legacy Fabric 1.8.9.
- `SHA256SUMS.txt` : sommes SHA-256 des JAR de cette release.

Installe un seul JAR BridgeTap dans le dossier `mods` de l’instance correspondante, puis redémarre Minecraft avec Java 8.

## Provenance de l’archive

Les binaires originaux sont conservés sans recompilation. Le fichier historique `BridgeTap.jar` est distribué sous le nom `BridgeTap-1.0.0.jar`, avec le même contenu. Commit d’archivage initial : [`327bb40`](https://github.com/sgggnnn/bridgetap/commit/327bb40abc4b7c3dedb7b99f664ebb6246e2e8ce).
